# Frontend Rules

Перед любым изменением UI обязательно полностью прочитать:

1. `PRODUCT.md`
2. `DESIGN.md`
3. `docs/FRONTEND_RULES.md`

## Definition of done

- Использованы существующие UI-примитивы; новый визуальный паттерн закреплён в `DESIGN.md` до повторного использования.
- В CSS нет `font-size` меньше `13px`; основной текст и поля — `16px`.
- Все интерактивные цели не меньше `44px`, есть `:focus-visible`, disabled/loading/error/empty состояния.
- Нет дублирующего заголовок текста, декоративной метрики без действия и повторного словесного логотипа.
- Светлая и тёмная оболочка Telegram, ширина `360px` и desktop проверены визуально; бренд-палитра Mini App остаётся неизменной.
- Выполнены `npm run typecheck`, `npm run lint`, `npm run build`.

## Запреты

- Не копировать разметку кнопок, карточек, полей, badge, notice и skeleton в feature-компоненты.
- Не использовать градиенты, glassmorphism, glow, размытую тень, emoji как системные иконки.
- Не добавлять command-first UX там, где действие можно выполнить кнопкой или обычным сообщением.
- Не показывать действие завершённым до успешного ответа сервера.
