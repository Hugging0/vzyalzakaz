# Источники и подбор подработок: сентябрь 2026

Цель — разовые задачи и небольшие проекты для русскоязычных разработчиков,
SMM-специалистов и видеомонтажёров. Число источников само по себе не является
метрикой качества. Проверять поступление уникальных подходящих заказов.

## Изменения

- FL.ru и Freelance.ru: публичные списки и полные описания. Частичные ошибки
  отдельных страниц записываются в CollectorRun; исчезновение разметки — ошибка,
  а не успешный пустой сбор. Отклики автоматически не отправляются.
- Добавлены Telegram-каналы zakaz_design и easy_wrk; четыре устаревших выключены.
- Telegram регулярно запрашивает историю даже без live-событий. Миграция
  `0010_collector_checkpoints` сохраняет последний обработанный message ID.
  Приоритет обхода — русскоязычные каналы с ручным откликом; пакет обработки
  одного канала ограничен 30 секундами, чтобы его очередь не задерживала остальные.
  При ошибке продолжение идёт с последней успешно записанной позиции.
- Явные дайджесты с отдельными заголовками и контактами разбиваются на задачи.
  Старый общий пост исключается из рекомендаций; история действий сохраняется.
- Подбор рассматривает активный корпус за 14 дней вместо последних 200 строк.
  Общий индекс прогревается по 64 описания каждые 120 секунд, попеременно по
  источникам. Запрос пользователя создаёт не более 32 недостающих эмбеддингов;
  неиндексированные кандидаты остаются в лексическом поиске. Это временно
  смешивает два способа оценки, поэтому сравнивать качество после прогрева.
- Неизвестный контент RU/multi повторно классифицируется по 8 записей каждые
  5 минут, один успешный повтор на модель. Ошибка провайдера прерывает пакет.
- Новые профили не получают не заданный человеком денежный минимум. Существующие
  предпочтения не меняются. Часовая ставка сравнивается с часовой целью.
- Нормализована полная занятость; React не извлекается из reactions;
  альтернативные инструменты не считаются одновременно обязательными.
  Отсутствие бюджета само по себе не понижает рейтинг. Веса рейтинга не менялись.

## Эксплуатация

LLM_PROVIDER=timeweb поддерживает OpenAI-совместимый чат. Для текущей выкладки
выбрана gemini/gemini-2.5-flash-lite после успешного пробного запроса: прежний
DeepSeek возвращал HTTP 402. Эмбеддинги остаются yandex/text-embeddings-v2-doc
и yandex/text-embeddings-v2-query через Timeweb. Секреты только в серверной .env.

При откате Git не откатывает таблицу checkpoints, факты, индекс, результаты
классификации и .env. До выкладки нужны резервные копии БД и конфигурации.
Обновление схемы обратно несовместимым не является: предыдущая версия просто
не использует новую таблицу. Для возврата LLM использовать резервную .env.

Проверять отдельно HTTP health, успешные CollectorRun, рост SourceOccurrence,
покрытие кэшем и содержимое подборок трёх одинаковых тестовых профилей.
Синтетические профили не создавать в production. Балл рейтинга не является
вероятностью получения заказа. Не все объявления новых источников подходят
нашей аудитории; полнота Telegram зависит от доступности сессии и прокси.
